# 40-Day JavaScript Learning Roadmap

This roadmap takes you from JavaScript fundamentals to building and sharing a small project. Aim for **1–2 hours a day**: learn the concept, write code yourself, and finish with the day's practice task.

## Week 1: JavaScript foundations

| Day | Learn | Practice |
| --- | --- | --- |
| 1 | What JavaScript is; running code in the browser console and Node.js | Print messages and simple values with `console.log()` |
| 2 | Variables: `const` and `let`; naming and reassignment | Store and update details for a fictional profile |
| 3 | Primitive data types: strings, numbers, booleans, `null`, and `undefined` | Create examples and inspect their types with `typeof` |
| 4 | Operators: arithmetic, comparison, and logical operators | Build a simple bill total and discount calculator |
| 5 | Strings, template literals, and common string methods | Format a greeting from first and last names |
| 6 | Type conversion and truthy/falsy values | Convert user-like input and test it in conditions |
| 7 | Review days 1–6 | Make a tip calculator using variables, operators, and strings |

## Week 2: Decisions, loops, and functions

| Day | Learn | Practice |
| --- | --- | --- |
| 8 | Conditional statements: `if`, `else if`, and `else` | Classify a number as positive, negative, or zero |
| 9 | `switch`, the ternary operator, and combining conditions | Create a menu-based choice or grade classifier |
| 10 | Loops: `for` and `while` | Print a multiplication table |
| 11 | `break`, `continue`, and nested loops | Find and print numbers matching a rule |
| 12 | Function declarations, parameters, and return values | Write reusable functions for common calculations |
| 13 | Function expressions, arrow functions, and default parameters | Rewrite yesterday's functions in different forms |
| 14 | Scope and review | Build a small number-guessing game in the console |

## Week 3: Arrays, objects, and modern JavaScript

| Day | Learn | Practice |
| --- | --- | --- |
| 15 | Arrays: indexing, length, and basic methods | Store a list of tasks and add/remove items |
| 16 | Array iteration: `forEach`, `map`, and `filter` | Transform and filter a list of numbers |
| 17 | More array methods: `find`, `some`, `every`, and `reduce` | Summarize a list of expenses |
| 18 | Objects: properties, methods, and property access | Model a book or product as an object |
| 19 | Destructuring, spread syntax, and optional chaining | Copy and update objects and arrays safely |
| 20 | Sets, Maps, and useful built-in methods | Remove duplicates and count repeated items |
| 21 | Review and practice | Build a contact list using arrays of objects |

## Week 4: The browser and asynchronous JavaScript

| Day | Learn | Practice |
| --- | --- | --- |
| 22 | HTML basics for JavaScript projects; selecting DOM elements | Select page elements and read their text |
| 23 | Updating text, attributes, styles, and classes | Make a button change a page heading |
| 24 | Events and event listeners | Create a click counter |
| 25 | Forms, input values, and basic validation | Build a form that displays a personalized greeting |
| 26 | DOM lists and event delegation | Add and remove items in a to-do list |
| 27 | JSON and browser storage (`localStorage`) | Save and restore a preference |
| 28 | Asynchronous concepts, callbacks, and timers | Use `setTimeout()` and `setInterval()` in a small demo |
| 29 | Promises and `async`/`await` | Write an async function and handle success and failure |
| 30 | Fetching data from an API | Request public data and display a useful result |

## Final 10 days: Build and strengthen

| Day | Learn | Practice |
| --- | --- | --- |
| 31 | Error handling with `try`/`catch`; debugging with DevTools | Deliberately fix bugs in a small script |
| 32 | Modules: `export` and `import` | Split a small app into separate JavaScript files |
| 33 | NPM basics and using a package | Initialize a project and explore its `package.json` |
| 34 | Clean code, naming, and breaking problems into steps | Refactor one earlier exercise for readability |
| 35 | Project planning and UI structure | Plan a weather app, quiz, or task tracker |
| 36 | Build the project: core functionality | Implement the main data and interaction flow |
| 37 | Build the project: browser interface | Connect the app to the DOM and handle user input |
| 38 | Build the project: persistence or API data | Add `localStorage` or a public API where appropriate |
| 39 | Test, debug, and polish | Try edge cases, fix issues, and improve the interface |
| 40 | Review and share | Write a README with setup steps, features, and what you learned |

## Suggested project choices

Pick **one** project for days 35–40:

- **To-do list:** add, complete, delete, and save tasks.
- **Quiz app:** show questions, track answers, and display a score.
- **Weather app:** search a city and display API results (requires an API key if the chosen service requires one).
- **Expense tracker:** record expenses and show totals by category.

## How to get the most from the 40 days

- Type the examples yourself instead of only watching or reading.
- Spend at least half of each session writing or changing code.
- When stuck, read the error message, inspect values with `console.log()`, and reduce the problem to a small example.
- Keep a short note of what you learned and what still feels unclear.
- If you miss a day, continue from where you left off; understanding matters more than the calendar.
- By day 40, aim to explain your project and its code in your own words.
